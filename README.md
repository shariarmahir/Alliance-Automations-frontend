# Alliance Automations frontend

Live monitoring, control and analytics UI for a garment dyeing floor, by Kandari-lab. Runs on a simulated 50-machine plant.

```bash
npm install
npm run dev        # http://localhost:3000
```

Open `/` for the landing page, `/dashboard` for the control room, `/tv` for the wallboard and `/tablet` for the operator screen.

Product, data rules and roadmap: [project.md](project.md). Working conventions: [CLAUDE.md](CLAUDE.md).
